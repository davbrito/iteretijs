# Changesets

This folder holds pending release notes. Run `npm run changeset` in a PR that
changes published behavior (`src/**`, exports, engines) and describe the change
for users: what changed, why, and how to update. While on 0.x, a breaking
change is a `minor` bump. Merging the "Version Packages" PR releases them.

See [CONTRIBUTING.md](../CONTRIBUTING.md) and https://changesets.dev.
